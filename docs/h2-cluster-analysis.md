# H₂・平均クラスタサイズを保存済みCSVから調べる

## PCでの実行

WSL/Linuxのリポジトリ直下で実行します。

```bash
git pull --ff-only
python3 scripts/analysis/analyze_h2_clusters.py
```

Python 3標準ライブラリだけでCSV・JSON・ZIPを保存できます。MatplotlibがあればPNG/SVGも作ります。
省略する場合は`--no-plots`を指定してください。Cの再ビルドや再シミュレーションは行いません。

`data/`以下に105試料すべてを含む保存先が1か所なら自動選択します。複数の控えや不足があるときは停止します。
その場合は実際の保存先を指定してください。

```bash
python3 scripts/analysis/analyze_h2_clusters.py \
  --suite data/report_figures/20261019T150945Z_9feb1c/simulation
```

このパスが異なる場合は元の`simulation`または`runs`フォルダへ置き換えます。
解析条件は`configs/analysis/h2-cluster-report.json`です。L=32/64/128、φtarget=0.1〜0.7、seed=3/17/42/101/202。
サイズ、占有率、seedの順に、既存のbenchmark形式のcase番号を割り当てます（反復はr1）。
別の条件群を扱う場合は新しい設定JSONを作り、`--config`で指定してください。並びとcase番号は元の計算に合わせます。
現版は3D・4腕・開境界の既存モデル用です。設定で腕長を変更できますが、境界条件・結合規則の変更は別途モデル検証が必要です。

## 読み込むものと保存先

各試料の`config.cfg`、`run.json`、`network-summary.csv`、`placement-summary.csv`、
`cluster-summary.csv`、`bonds.csv`を読みます。CSVは`.csv.gz`も扱えます。
同名の圧縮前後が両方あると入力を一意に決められないため停止します。原データは自動削除しません。
`trajectories.csv`は読みません。

出力先は`data/analysis/h2_<UTC日時>_<識別子>/`です。`--output PATH`で新しい保存先も指定できます。
既存の出力フォルダを上書きしません。元CSV検証中に不整合があれば、集計結果の保存前に停止します。
図作成など保存段階のエラーがあれば途中の出力が残る場合があります。成功は末尾の`SUCCESS`と`run_manifest.json`のstatusで確認します。

| 出力 | 内容 |
|---|---|
| h2_samples.csv | 各試料のH₂、規格化、クラスタ統計 |
| h2_summary.csv | 各条件の平均・試料SD・有効数・最小・最大 |
| cluster_histograms.csv | 試料ごとのサイズsとクラスタ数 |
| analysis_config.json | 解析条件の控え |
| run_manifest.json | 入力パスとSHA256、解析コードSHA256、Gitコミット、測定定義、描画状態 |
| upload_h2_cluster_results.zip | 上記結果と、作成した図の送付用ZIP |

`SUCCESS: 105 samples, 21 conditions`を確認し、`UPLOAD THIS FILE:`の直後に表示するZIPを送ってください。
エラーの場合は全文を送ってください。旧ZIP版の`ab_saw_h2`はこのコマンドでは使用しません。

## H₂と規格化

H₂は同じ2分子が**ちょうど2本**で結ばれたペアの数です。1ペアに2分子閉路が1個あります。
三重・四重結合のペアを主指標に含めず、H₂を全閉路数の近似とは呼びません。
H₁〜H₄は元の結合本数の検算用にmanifestへ記録します。

N：実際に配置された全分子数、E：成立結合数、K：孤立分子を含む全クラスタ数、N₁：最大クラスタの分子数。

| 量 | 式 |
|---|---|
| 格子点あたりのH₂ | H₂/L³ |
| 結合済み末端のうち、H₂ペアに使う割合 | 4H₂/(2E)=2H₂/E |
| 全末端のうち、H₂ペアに使う割合 | 4H₂/(4N)=H₂/N |
| 末端結合率 | p=E/(2N) |
| 実占有率 | φ=(1+4l)N/L³。腕長5ならφ=21N/L³ |
| 格子全体に対する最大クラスタ占有率 | S₁=(1+4l)N₁/L³=φPmax |

H₂/N=p×(2H₂/E)を検算します。E=0のときEを分母とする量は未定義です。
同じφでLを変えると分子数も増えるため、生のH₂とH₂/L³の両方を比較します。
3サイズ・5seedだけから漸近的な指数や収束値を決めません。

## 平均クラスタサイズ

sは各クラスタの分子数です。

- 算術平均：Σs/K=N/K。クラスタを等確率で選んだときの平均。
- 全クラスタの重み付き平均：Σs²/Σs。
- 主な追加量：各試料の最大クラスタ1個を除いたΣ′s²/Σ′s。

最大が同率なら最小cluster_idの1個を除外し、同率最大をすべて除いた値も感度確認用に保存します。
孤立分子は含みます。除外後の残余が空ならnull/CSV空欄とし、0にしません。残りが孤立分子だけなら1です。
最大クラスタの除外は転移前後で同じ規則です。「有限クラスタ」の厳密な判定を行ったという意味ではありません。

先に各試料の比を求め、seed間で平均します。クラスタヒストグラムを全seedで合算した比とは区別します。
エラーバーは試料SD（ddof=1）で、信頼区間ではありません。図の線は補助線です。
有効数nを各量に記録し、未定義の試料を0として平均しません。

## 検証範囲

設定・完了状態、Σs=N、ΣEᵢ=E、クラスタ数K、最大N₁、結合数、末端IDの所有者・重複を照合します。
型・腕・距離・座標の列がある場合はそれらも検査します。SHA256は読んだ圧縮ファイル自体のバイト列に対する値です。
これは保存CSVの整合性確認であり、生成分布の妥当性、全軌跡の非重複や、CSVからの連結成分の再構築を検証するものではありません。

```bash
make test-analysis
```

小規模な既知の構成例を使い、CSV/gzip読込みからZIP作成までを検証します。ユーザーPCの105試料の実測はPCでの実行後に確認します。
