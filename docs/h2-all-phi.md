# H₂末端割合とクラスタサイズ：全61占有率での確認

## 問い

Φ=0.44だけを見ていたため、この傾向が他の占有率でも見えるかを先に確認する。
生成は行わず、18,300試料のsize_relation.csv（3,115行）をすべて使用する。
L=32/64/128、目標Φ=0.10〜0.70、0.01刻み、各条件100独立seed。

## 観測

- L64とL128では、全61占有率で、2分子クラスタの平均H₂末端割合が5〜8分子クラスタより高かった。
- 最大クラスタを1個除いた集計でも、L64/L128では同じ平均値の大小関係が全61占有率で見られた。
- L32では全クラスタの場合61条件中59条件で同じ向き。低密度側の2条件では逆向きだった。最大1個除外では有効seed50以上を満たす59条件中57条件。
- これは平均値の大小を記述した比較であり、61条件すべてに有意差があるという検定結果ではない。隣接サイズを含む全域単調性も主張しない。
- 同じクラスタサイズ区間でもΦで割合が変わる。Φ0.44で見た「大きいクラスタで約5%」を全占有率の一定値として一般化しない。
- 低密度側では大きなサイズ区間のクラスタがそもそもない。高密度側では小さい残余クラスタと最大クラスタの間に、出現頻度の低いサイズ区間がある。
- 最大クラスタを除くと高密度側の巨大サイズの帯が消える。元の下段のへこみを理解するには「全クラスタ」と「最大1個除外」を分けて見る必要がある。

L128、全クラスタの試料内クラスタ平均→seed平均（単位%）：

|目標Φ|2分子|5〜8分子|17〜32分子|
|---:|---:|---:|---:|
|0.20|5.97|4.93|4.27|
|0.44|7.82|6.59|5.59|
|0.70|9.75|8.55|7.09|

この表の各区間は各条件100seedが寄与。SE・全サイズ・他のLはall_phi_table.csvと図を参照。
表は条件をそろえた相関の記述。H₂が成長を妨げたかの因果は分からない。
h₂/sの分母s、クラスタサイズ区間に入った試料の選択、配置と端末位置の影響も切り分けていない。

## 図の5点

### 07_all_phi_fraction（全濃度×サイズの末端割合）

1. 目的：Φ0.44で見たサイズ依存が全濃度でも現れるかを一覧で確認。
2. 定義：横軸は目標Φ、縦軸はクラスタサイズ区間、色は平均100h₂/s (%)。列はL、上段は全クラスタ、下段は最大1個除外。
3. 計算：各試料で区間内のクラスタを等重み平均し、寄与seedを等重み平均。全61Φを使用。色のスケールとサイズ区間は全パネル共通。
4. 観測：孤立分子を除く小さいサイズで割合が高い領域が複数のΦに現れ、同じサイズでも高密度側で割合が上がる。
5. 限界：有効seed50未満は灰色（灰色の点は存在するが希少）。灰色は割合0ではない。閾値50は表示上の基準で精度保証ではない。ヒートマップでは誤差棒を表示しないため09/10と合わせて見る。

### 08_all_phi_availability（区間の存在頻度）

1. 目的：サイズ関係を比較できる範囲と、試料が少ない範囲を把握する。
2. 定義：横・縦は07と同じ。色はその区間のクラスタが1個以上あるseed数/100。今回n=100なので百分率の数値とseed数が等しい。
3. 計算：size_relation.csvのsamples_with_binを使用。区間の行がない場合、存在試料数は0。H₂割合の0とは区別する。
4. 観測：全クラスタでは高密度側に巨大クラスタの帯が現れ、最大1個除外では消える。
5. 限界：クラスタの個数分布・分子数割合ではない。1個あっても100個あっても、そのseedは1として数える。

### 09_density_comparison（代表条件比較）

1. 目的：低密度、従来の参照条件、高密度でサイズ依存の形を比較。
2. 定義：Φ=0.20/0.44/0.70。横軸はサイズ区間の幾何中心・対数軸、縦軸平均100h₂/s (%)。上下は全クラスタ/最大1個除外。
3. 計算：各条件の平均とSEをCSVから使用。全パネルを同じ軸範囲にし、有効seed50以上の区間だけを描く。線・fitなし。
4. 観測：Φ0.44以外でも、複数サイズ区間で小さいクラスタの割合が高い。高密度側の割合の水準も高い。
5. 限界：未表示の希少区間の割合を0や低い値と解釈しない。全域の判断は07/08で先に確認し、代表3点だけで一般化しない。

### 10_fixed_sizes_across_phi（固定サイズ区間の濃度依存）

1. 目的：サイズ依存と占有率依存を混同せずに見る。
2. 定義：横軸目標Φ、縦軸平均100h₂/s (%)、色は2、5〜8、17〜32、65〜128分子。3パネルでL比較。
3. 計算：全クラスタの区間平均±SE、有効seed50以上のみ表示。点は結ばない。
4. 観測：同じサイズでも占有率が高い条件で割合が高くなる傾向。L128は小サイズ区間の平均値の順序が比較的はっきり見える。
5. 限界：サイズ区間が存在するseedの集合はΦごとに変わる。異なるΦは同じクラスタの成長時系列ではない。
