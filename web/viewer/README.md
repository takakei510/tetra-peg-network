# AB-SAW 3Dビューア

WebGLで分子の腕と成立結合を線描画する、ブラウザ内完結の静的ビューアです。
外部JavaScriptライブラリ・CDN・データアップロード・インストールは不要です。
WebGLとES Modules / Module Workerに対応する新しいブラウザで使用してください。

## 開き方

ホストされたページを開くか、リポジトリのルートで次を実行します。

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory web/viewer
```

`http://localhost:8000`を開きます。`index.html`を直接ダブルクリックする方法は、モジュールとWorkerの制約により対応しません。

## データと操作

- 同じ実行の`trajectories.csv`と`bonds.csv`をまとめて選択・ドロップします。
- 軌跡CSVは必須、結合CSVは任意。候補CSVを成立結合として読み込まないでください。
- 軌跡だけの場合、クラスタ数・最大成分・成分別着色は未判定になります。
- 左ドラッグで回転、ホイールで拡大縮小、Shift＋ドラッグで平行移動します。
- キーボードは矢印で回転、＋／−で拡大縮小、Rでリセットです。
- A/B型、腕、結合の表示切替、XY/XZ/YZの視点、PNG保存を使用できます。
- 最大成分は結合からブラウザ内で再集計します。同率の場合は所属分子の最小IDが最小の成分を表示します。
- 成分別着色では同じ成分を同じ色で示します。色の重複はあり得ます。
- PNGには表示分子数と間引き状態を記載します。動的な物理シミュレーション機能ではありません。

通常は基本的な型・ID・腕長・末端の重複使用を検査し、表示を優先します。
「詳細検証を実行」で、最近接移動・占有点重複・CSV間の末端座標・結合距離も検査できます。
画面とPNGに詳細検証済み／未検証を明記します。未検証の点数表示は行数であり、重複がないことを保証しません。
現行C出力のカンマ区切り数値CSV専用です。一般的な引用符付きCSVの読込みは対象外です。

## 大規模データの扱い

- CSVの合計32 MiB、軌跡50万行、結合20万行を上限とします。60秒を超える読込みは中断します。
- 最大描画数は1,000／5,000／20,000分子から選べます。超過時は分子ID順に等間隔で分子単位の間引きを行います。
- 腕は途中で切らず、選択分子の4本すべてを表示します。結合は両分子が表示対象の場合だけ描きます。
- 分子数・占有点数・結合数・最大成分・成分別着色の所属は、間引き前の全入力から求めます。
- 間引き表示は空間構造を完全には表しません。表示の疎密だけから結合密度を判断しないでください。
- 読込みをWorkerへ分離し、描画は視点・表示の変更時だけ実行します。大きなCSVは読込み時にもメモリを使います。
- 実用上限はPC・ブラウザ・GPUによって変わります。現時点では実機での大規模性能検証は未実施です。

ビューアの統計値は既存の研究用CSVに代わる正本ではありません。元の実行フォルダ・条件・seed・未達状態も保存してください。
現在は`config.cfg`を読み込まないため、系サイズL、境界箱、占有率phiは推定表示しません。


## 読込みの状態と軽量データ

処理段階の進捗表示と中止ボタンを用意しています。進捗の百分率は段階の目安で、ファイルバイト数の進捗ではありません。
Workerの起動応答が2.5秒以内になければ、合計2 MiB以下の入力は直接読込みへ切り替えます。
大きな入力でWorkerを使えない場合は、再読込みまたはローカル起動を案内します。
直接読込みでは小さいデータでも一時的にメインスレッドを使用します。60秒の中断は同期処理自体を強制停止する保証ではありません。

「表示専用JSONを保存」で、現在の全入力（描画間引き前）を`model.ab-saw.json`として書き出せます。
次回はその1ファイルだけを選択します。座標を配列で持ち、CSVの多数の行を分割する処理を省きます。
クラスタ所属は読込み時に再計算し、JSON内の検証済み状態を信用せず、毎回「詳細未検証」から始めます。
これは研究用の実行条件・元CSVの代わりになる保存形式ではありません。座標・形状・成立結合のみを保存します。

保存済みCSVからPythonで事前変換することもできます（物理モデルを変更しない後処理です）。

```bash
python3 scripts/export_viewer.py \
  --trajectories data/runs/<実行フォルダ>/trajectories.csv \
  --bonds data/runs/<実行フォルダ>/bonds.csv \
  --output model.ab-saw.json
```

出力先は上書きしません。現在のC出力順を前提とし、一般的な並べ替え済みCSVは対象外です。
この形式でも軌跡点数の上限は変わりません。巨大試料を無制限に表示するための圧縮形式ではありません。


## 表示されない場合への対応（2026-10-15）

標準の描画をCanvasによる互換描画に変更しました。3次元座標をカメラで投影するので、回転・ズーム・移動は引き続き利用できます。
GPUのWebGL描画はURL末尾の`?renderer=webgl`で選べます。失敗時は互換描画へ自動で切り替わります。
互換描画ではワイヤーの重なりを透視表示し、奥の線を隠しません。交差が接続を意味しない点は同じです。

読込み結果を画面に渡す処理で例外が発生した場合もエラーを表示します。
ステータスの「表示成功」は描画処理が完了した段階で表示し、CSV読込み完了と区別します。
UI契約テストではサンプルの読込みから表示件数・ファイル名・描画呼出し・成功表示まで検査します。
このテストは実ブラウザや実GPUでの操作検証の代替ではありません。
