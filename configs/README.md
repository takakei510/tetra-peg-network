# 設定ファイルの置き方

- `demos/`：動作確認用の見本。名前には用途・L・seedを入れる。
- `local/`：手元で条件を変える作業用。Git対象外。見本をコピーして使う。
- 将来の統計実験用設定は `experiments/` に分ける。現段階のデモと混ぜない。
- `default.cfg` と `two-molecules.cfg` は既存コマンドとの互換用として残す。

cfgから変更できるのは現在 `dim`、`L`、`seed` の3項目だけ。AB-SAWデモはdim=3を必要とする。
未知のキー・重複キーはエラーになるので、未対応の設定を書き足さない。

| 条件 | 1分子デモ | 2分子デモ |
|---|---|---|
| 目標分子数 | 1 | 2 |
| 分岐数・腕長 | 4腕・5歩 | 4腕・5歩 |
| 型 | A確率0.5 | A、Bの順に固定 |
| 境界・成長 | 開境界・空近傍一様選択・腕順次生成 | 同左 |
| 最大配置試行数 | 10000 | 2分子合計10000 |
| 結合 | なし | twoは配置のみ。bondsモードで結合を選択 |

これらはデモのCコード内の固定条件。実行時には `metadata.log` と `run.json` に残す。
腕長・分子数・型の抽選方法を設定可能にする改修は、量産実験用の生成処理を作る段階で行う。
③-Aのcandidatesモードはマンハッタン距離1～2を固定条件とし、metadataに記録する。
距離をcfgから切り替える機能はまだない。未知のキーをcfgに記しても有効にはならない。
`demos/candidates_L8_seed3.cfg` は候補が見つかる例として用意した見本。

実行のたびに、使用したcfgを結果フォルダへコピーする。その後見本や作業用cfgを変更しても、過去の実行条件は残る。

③-Bの`demos/bonds_L8_seed3.cfg`は3候補から2結合を得る確認例。
末端順シャッフルと未結合相手の一様抽選、多重結合許可はdemo_bonds内の固定条件。
これらの条件もmetadataに記録し、cfgに未対応キーを追加しない。
