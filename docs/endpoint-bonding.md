# ③-B：末端順のランダム結合

## 今回の条件

③-Aで得た、マンハッタン距離1～2の異種A–B候補を入力する。
全末端IDをFisher–Yatesで一様な順序にシャッフルし、順に次の処理を行う。

1. 既に結ばれた末端は飛ばす。
2. その末端の候補のうち、現在未結合の相手を数える。
3. 相手がいれば一様に1個選び、両末端を結合済みにする。
4. 相手がいなければ未結合のまま次へ進む。

ユーザーが選択した実装条件であり、先生の資料が抽選手順まで指定したとは断定しない。
デモは同一分子対の別腕の結合を許可する（`allow_multiple_bonds=1`）。
`bond_select`の引数を0にすれば同一分子対の複数結合を禁止できる。cfgからの切替はまだ未対応。
分子は単一のA/B型なので異種条件で自己結合を除外する。
確率pによる追加の結合抽選は行わない。`bond_fraction=2*bonds/(4*N)` は得られた結合率。
N=0ではこの率は未定義。固定2分子のデモはN>0でのみ計算する。

## ランダム化の意味

各末端の処理順と、その時点で空いている相手の抽選をランダム化する。
全候補ペアをシャッフルする方法とは分布が異なる。
全マッチングを一様に抽出する方法でも、結合本数を最大化する方法でもない。
多重結合許可時は未結合同士の候補が残らない「極大マッチング」になる。
例えば候補0–4、0–5、1–4は、0–4だけなら1本、0–5と1–4なら2本になる。
乱数には既存の`rng_bounded`を直接利用し、整数抽選の剰余偏りを避ける。
デモは分子生成後の乱数状態を引き続き使用する。seedに加え、生成・候補の列挙順とコード版も再現条件。

## データの保存

`BondStore`の`pairs[bond_id]`は成立した2末端ID。
`bond_at_endpoint[endpoint_id]`は結合IDで、未結合は`SIZE_MAX`。
結合IDは成立順に0から付ける。末端ペアはIDの小さい方をa、大きい方をbにする。
aは必ずしもA型ではない。
座標・型・所属分子・腕は既存のMoleculeStoreから取得し、結合構造体には重複保存しない。
候補配列を結合配列へ上書きしない。元の格子・分子軌跡も変更しない。

```sh
python scripts/run_demo.py --mode bonds --config configs/demos/bonds_L8_seed3.cfg
```

同じ実行フォルダに`trajectories.csv`、`candidates.csv`、`bonds.csv`、`molecules.png`を保存する。
`bonds.csv`は`bond_id`と、2末端のID・所属分子・腕・型・site・座標・マンハッタン距離を持つ。
`metadata.log`と`run.json`に抽選方法、多重結合条件、乱数の使用方法、結合数、結合末端数、結合率を記録。
候補0件・結合0本も正常終了。図の緑実線は確定した接続を表す。
中間格子点の経路を新しく生成・占有する処理は行わない。実線は距離条件の判定経路ではない。

## 計算量と責務

末端数E、候補数Cとして、候補を両向きの連続隣接配列へ一度まとめる（CSR形式）。
各末端の候補は最大24件。重複検査もこの上限内で行う。
隣接配列の準備、末端シャッフル、相手選択を合わせてO(E+C)、追加メモリO(E+C)。
多重結合禁止時の分子対検査は最大4腕なので固定定数。
実測の高速化倍率はまだ評価していない。
`bond_select`は③-Aの正しい候補を前提とし、型と距離を再判定しない。
ID範囲・ID順・同一分子・重複候補・24件上限・配列サイズを検査する。
エラーは乱数を使う前に返し、出力を変更しない。

## 検証と既存コードの利用

人工候補で末端の競合、1本/2本の結果、多重結合の許可/禁止、逆引き、0候補、0末端、
不正IDと重複の拒否、同じseedの再現、入力候補不変を検証。
6分子を実際に生成した50seedで、候補への包含、A–B、距離、1末端1結合、
逆引き、格子と軌跡の不変を確認。許可時は極大性も確認する。

そのまま使ったもの：`molecule_try_generate`、`endpoint_index_build`、
`endpoint_find_candidates`、`rng_bounded`、軌跡添字と格子座標変換。
描画のCSV型・座標・距離検査は既存`read_candidates`を直接再利用。
新しく作ったもの：末端順の抽選、候補の隣接配列、BondStoreと逆引き、結合CSVと緑実線。
Union-Findはまだ呼ばない。次段階で結合ペアの分子IDをunionし、孤立分子を含むクラスタを集計する。
同じ分子対に2本結んでもUFでは1クラスタであり、結合の本数はBondStoreで別に保持する。
