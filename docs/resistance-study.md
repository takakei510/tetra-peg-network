# AB-SAW抵抗解析の初期観測（各条件100試料）

## 目的と実験条件

占有率・系サイズを変え、電極間の接続、伝導の大きさ、電流経路の広がりを評価する。
初期条件はL=32,64,128、目標占有率0.10〜0.70を0.01刻み、seed 3〜102の各100試料。合計18,300試料。
腕長5、A型確率0.5、開境界、多重結合許可。電極はx方向最外1層、電位差1、全枝抵抗R0=1。
生成コードは既存版を使用し、電極条件は解析JSONで指定する。
サイズごとの別実験にする場合は、設定のsizesを変更し、別の出力フォルダを使う。

## 入力と保存

既存のh2_relation_fine_compactは分子軌跡・コア座標を保存しないため、そのデータだけから今回の電極ノードを復元できない。新たに試料を生成する。
各試料でconfig.cfg、分子コア行だけを残したtrajectories.csv.gz、成立結合のbonds.csv.gzを保存する。
これは分子粗視化抵抗網を再解析するための最小入力。全腕のSAW経路を描き直すには、フル軌跡を別途保存する必要がある。
node-potentials.csv.gz、bond-currents.csv.gz、試料ごとのresult.jsonも保存する。
ルートのstudy.jsonに設定、Python/NumPy/SciPy、コードのコミット、実行バイナリと解析コードのハッシュを記録する。

## 最初に見る5図

1. 貫通率と占有率
   全正常試料に占める連結試料の割合。95% Wilson区間を付ける。
   同じ占有率でのサイズ差と、立ち上がり領域を調べる。接点なしの正常試料は非貫通として数える。

2. 平均コンダクタンスと占有率
   全正常試料でのG_eff*R0の平均と±1標準誤差。
   この電極規則で接点がない試料は電流0と解釈し、集団平均にはG=0を与える。元の解析結果の接点なし状態・未定義Gは保持する。
   両面に接点がある試料だけの平均Gも別列に保存し、境界条件に依存する欠測の影響を確認できる。
   Gは試料形状を含む量。サイズ差をそのまま材料導電率の差と解釈せず、幾何学換算を別途定義する。

3. 連結試料の抵抗分布
   R_eff/R0の中央値と25〜75パーセンタイルを表示する。下段に連結試料数を示す。
   四分位範囲は試料間のばらつき。中央値の信頼区間とは異なる。
   非連結の無限大抵抗は有限値の分布に含めず、図1の貫通率と併せて解釈する。

4. 電流を担う結合の割合
   |I_e|/(DeltaV/R0)が1e-12、1e-10、1e-8を超える結合数を、全成立結合数Eで割る。
   各連結試料で比を計算してから平均し、±1標準誤差を表示する。
   3つのしきい値で安定性を確かめる。測っているのは指定電極で電流を担う枝の割合である。
   電極から離れた成分や無電流枝も分母Eに含まれる。

5. 電力散逸に参加する結合の広がり
   各試料でQ=(sum_e P_e)^2/(E*sum_e P_e^2)を求め、連結試料で平均する。
   全E本が同じ電力を担えばQ=1、1本だけが担えばQ=1/E。低いほど散逸が一部の結合へ集中する。
   しきい値を使う図4を、電流の大きさを連続的に反映する指標で補う。

## 統計・計算の扱い

- 独立単位は1試料。枝を独立試料として標準誤差を計算しない。
- 同じseedを占有率間で使うため、占有率間の観測には相関がありうる。
- generation_incomplete、generation_error、analysis_errorを別々に記録し、正常試料数、接点なし件数、連結試料数、未計算件数を出力する。
- 配置未達や計算失敗を非貫通に置き換えない。正常試料が100未満なら、その条件は予備結果として扱う。
- 出力CSVを1条件ごとに更新し、試料ごとのJSONは1試料ごとに保存する。中断後は同じ設定・コード・バイナリで再開できる。
- 失敗試料は記録を保ち、--retry-failedで再実行する。試料は同じseedで再生成する。
- 設定や解析コード、生成バイナリが変わった場合は、新しい出力先を使う。
- エラー時もログと保存済みの成功試料を保持する。
- 電流保存、電極電流収支、散逸電力収支は既存ソルバーで検査する。相対電流収支も試料ごとに保存する。
- 現段階で無限系の閾値・臨界指数・ゲル弾性率を推定する解析は含めない。

## Colabの実行

notebooks/Resistance_study_100_colab.ipynbを開き、上から実行する。
MODE="smoke"はL=16,32、占有率0.10,0.45,0.60、各2試料の12試料。図の数値は動作確認結果である。
MODE="full"は初期設定の18,300試料。終了・中断後に同じOUTPUTで再開する。
RUN_IDは既定を固定し、fullでも実行のたびにフォルダを作り直さない。別設定で新実験を始める場合にRUN_IDを変える。
出力先はDriveのtetra-peg-network/resistance_analysis/studies/<RUN_ID>/<MODE>。
各図はPNGとSVGで保存し、試料CSV、条件別集計CSV、図の説明を含む小さな共有ZIPも作る。
必要に応じてSIZE_OVERRIDE=[32]などを指定し、出力RUN_IDを分けて段階的に測定できる。
