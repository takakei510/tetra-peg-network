# L=128 全占有率の4分子・6分子閉路

## 調べること
占有率によって短い閉路の存在量がどう変わるかを調べる。まず最大クラスタを含む全クラスタの個数を報告する。対象は保存済みL=128、目標φ=0.10〜0.70の0.01刻み、各100試料（6,100試料）。ネットワークを生成し直さない。

出力図は横軸を実占有率、縦軸を(1)1試料あたりC4/C6個数、(2)分子100個あたりC4/C6個数とする。後者は各試料で100*Ck/Nを求めてから平均する。全分子数Nもφとともに変わるため両方を示す。単位は個/100分子で、百分率ではない。各条件は独立な100試料の平均±SE。閉路0の試料も平均に含む。

## 実行
リポジトリ直下で実行する。

```bash
git pull
python3 scripts/analysis/analyze_cycles_46_all_phi.py --mode pilot
```

pilotはφ=0.10,0.43,0.70から各1試料を処理する。高占有率ではグラフ規模・結合構造が違うため0.43の旧実行時間を全範囲に外挿しない。このpilotからも全6100試料の所要時間は保証できない。

```bash
python3 scripts/analysis/analyze_cycles_46_all_phi.py --mode run
```

100試料ごと（占有率1条件ごと）に進捗を表示する。1試料を処理中は出力が止まることがある。既定の入力はstudy内のcompletedなresults_*から試料数・更新日時順で選ぶ。特定のCSVを使う場合は`--samples-csv PATH`、研究データの場所が違う場合は`--study PATH`を指定できる。

## キャッシュと検証
DFS実装は既存analyze_cycles_46.pyのSHA256=d16eede57d87d37ae3578454847ea6655b4124bb6fdd19be35804f7dbbdd9faaへ固定。分子列としての単純閉路を数え、開始点・方向の重複を除く。弦ありも含む。並列辺の選び分けをした個数は参考列に別保存。独立閉路数E-N+Kとは区別する。

各試料の元bonds.csv(.gz)とcluster-members.csv(.gz)をハッシュ照合し、試料定義とDFSコード・形式が合う既存cycle46_cacheを再利用する。0.43もこの条件で再利用。新規抽出時は従来のBFS所属・次数・N/N1/K/H2/結合数の整合性検証を使う。

新規の再開用キャッシュは`cycle46_all_phi_cache/<engine_hash_prefix>/`へ総数だけを保存する。試料単位で完了するたびに一時ファイルから置換し、中断時も完了分を再利用できる。入力CSV全体のハッシュも開始・終了で照合する。設定にある全条件・各試料数がそろわなければ全条件の図を作らない。

## 共有するもの
完了時の`SHARE:`で示す`cycle46_all_phi_share.zip`をDriveのcycle46_reportへアップする。ZIPには2図×PNG/SVG、試料別総数CSV、占有率別平均/SD/SE/最小最大CSV、metadata、図の説明を含む。CSVと集計は全6100試料、図は全61条件。

L128・全占有率のみの結果であり、系サイズ依存や無限系臨界点の確定、閉路がクラスタ成長を抑制する因果を直接示さない。最大クラスタ除外のサイズ別図と集計対象が異なる。

## 検証
テストには既知の正方形2成分を用いた複数占有率の人工データを使う。既存キャッシュ再利用、pilotからrun、再実行時のcompact-cache再利用、元ファイル変更時の再解析、gzip入力・出力ZIP、平均比と合算比の区別、0個試料の取り込み、試料不足・重複seed・DFSコード不一致の拒否を確認する。人工データを研究結果として使わない。
