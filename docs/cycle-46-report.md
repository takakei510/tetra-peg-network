# 4分子・6分子閉路を報告するための追加解析

## 目的と今回の範囲

問いは「2分子間の二重結合だけでなく、4・6個の異なる分子にまたがる閉路が、どのサイズのクラスタに現れるか」。クラスタを大きくする接続と、すでにつながった分子間の閉路形成を区別するための構造解析である。静的な観測から、閉路が成長を抑制した因果は結論しない。

まずL=128、目標φ=0.43の既存100試料を使う。これは今回のL128で平均Sfinが最大となる測定点であり、臨界点と確定した値ではない。全183条件を最初から解析し直すことは今回の必須条件にしない。主図では従来のH2解析に合わせ、各試料の最大クラスタを1個除く。全クラスタの集計もCSVに残す。

## 数える閉路の定義

4分子閉路は4個、6分子閉路は6個の**異なる分子**を通り、最後に開始分子へ戻る単純閉路。開始分子の変更、回転、逆向きは同一として数える。途中で分子を再訪する経路は数えない。弦がある閉路も含むため、最小環・原始環だけを数える解析とは異なる。

同じ分子ペアの多重結合については、以下を区別する。

- C4_mol、C6_mol：分子列として異なる閉路数。並列辺を1本にした単純射影で数える。主図に使う。
- C4_edge、C6_edge：成立結合の選択まで区別する閉路数。分子列ごとに各ペアの結合多重度の積を足す。試料別CSVに残す。
- H2：従来通り、ちょうど2本の成立結合を持つ分子ペア数。3本・4本ペアは含まない。H2をC2の全数と呼ばない。

これらは独立閉路数E−N+Kとは異なる。

## 図と答えたい問い

|出力|問い|測定量|
|---|---|---|
|01_endpoint_participation|どのサイズのクラスタで、閉路に関わる末端が多いか|H2、4分子、6分子それぞれの参加末端割合|
|02_cycle_counts|分子数に対して閉路がどれだけ現れるか|C4_mol/s、C6_mol/sを分子100個あたりで表示|
|03_support|各サイズの比較に何試料が寄与しているか|寄与試料数と、全100試料あたりの平均クラスタ数|

4/6分子閉路が使う成立結合の**和集合**の大きさをB4、B6とし、参加末端割合はqk=2Bk/(4s)。同じ長さの閉路が同じ結合を共有しても、その結合・末端は1回だけ計上する。並列結合のあるペアが分子閉路に参加するなら、そのペアの成立結合はそれぞれ参加可能なので全て和集合に含む。4C4や6C6から割合を作ると共有結合を重複計上するため採用しない。

qH2=4H2/(4s)=H2/s。q4・q6・qH2は互いに重複し得るので足し合わせない。閉路個数密度は%ではなく、100を超えても異常ではない。

試料内は区間内のクラスタ等重み平均、次にその区間がある試料間の等重み平均。区間が存在して閉路0なら0として含み、区間自体がなければ割合平均から除く。SEと有効試料数を出す。n=50は表示上の目安で、統計精度の保証ではない。

s<4ではC4=0、s<6ではC6=0となる構造的な制約がある。5〜8分子区間には6分子閉路が不可能な5分子クラスタも含まれる。こうした制約だけを発見として報告しない。

## デスクトップPCのWSLで実行

研究リポジトリ内で実行する。入力は前に計算した `data/validation/h2_relation_fine_compact/cases` に残る成立結合と所属CSV。`samples.csv`だけでは閉路を復元できない。Driveの大きいバックアップをColabに全展開する作業より、元データのあるPCで計算して小さい結果だけ共有する流れを優先する。

```bash
git pull --ff-only
python3 scripts/analysis/analyze_cycles_46.py --mode pilot
```

既定では完了済み `results_*` の中から試料数が最多の集計を選ぶ。選んだL128・φ0.43の100試料について必須の原CSVが存在するか先に確認する。pilotは先頭1試料だけを計算し、元のN/E/K/N1/H2と分子の所属・次数を照合する。途中にエラーがあれば100試料の実行へ進まず、エラー全文を共有する。

pilotが成功したら実行する。

```bash
python3 scripts/analysis/analyze_cycles_46.py --mode run
```

Matplotlibがなければ、普段使用しているPython環境に導入する。

```bash
python3 -m pip install matplotlib
```

保存場所を明示する場合：

```bash
python3 scripts/analysis/analyze_cycles_46.py --mode pilot \
  --study /path/to/h2_relation_fine_compact \
  --samples-csv /path/to/results_fe428bde2d/samples.csv
```

設定は `configs/analysis/cycle-46.json`。同じコマンドを再実行すると、コードと入力SHA256が一致する試料のチェックポイントを再利用する。DFSの途中で中断しても、完了した試料から再開できる。キャッシュはstudy内 `cycle46_cache` に作る。全100試料の成功後だけ、study内 `cycle46_outputs/<日時>/cycle46_share.zip` を出力する。このZIPをChatGPTに添付する。

## 計算と検証

長さ6までの深さ制限付きDFS。単純射影で次数0・1の頂点を反復除去した2-coreだけを探索する。最小分子IDを開始点にし、最初の隣接分子IDと最後の分子IDの大小で逆向きを除く。閉路列を全件保存せず、個数と参加ペアの集合を保持する。元の多重次数は4以下なので、全長の単純閉路を列挙する方式より探索を制限できる。ファイル読み込み・BFS照合・試料間のばらつきもあるため、実データの所要時間はpilotで確認する。

検証は木、正方形、六角形、共有辺のある閉路、並列辺、孤立分子、同率最大、K3,3、K4,4、ランダム小二部グラフの独立全探索との一致。不正な末端再利用や非二部グラフは拒否する。実試料の測定結果はPC実行後に確認し、検証用人工グラフを研究結果として提示しない。
